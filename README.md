Авторский алгоритм реализованный на С++ для построенния оптимального пути на поверхности, которую можно представить в дискретном виде.

<img width="444" height="375" alt="Снимок экрана от 2026-05-15 19-06-42" src="https://github.com/user-attachments/assets/819bc118-f93a-4cb9-9119-04bd70f6770b" />

Так же в программе есть адаптация поиска в ширину для сетки высот.

Требуется установка зависимостей, подробнее в скрипте setup (для linux mint достаточно запустить скрипт)

При первом запуске, а также после внесений изменений в коде:
    make clean
    make

Запуск:
    ./program
